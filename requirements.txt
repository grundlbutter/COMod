# Python dependencies for the COMod toolkit.
#
#     pip install -r requirements.txt
#
# That is the whole list. Everything else in this repository is Python
# standard library: the WDF reader, the C3 mesh parser, the DDS/BC decoder
# and the viewer's HTTP server are all stdlib-only by design.
#
# Verified by parsing every .py under core/, tools/, tests/ and blender/
# for imports and subtracting the standard library: PIL and numpy are the
# only two names left.
#
# No browser driver, no C compiler, no 7-Zip, no node. The thumbnail
# renderer is a software rasteriser written in numpy; nothing here shells
# out to anything you have to install.

# REQUIRED.
#   Every texture the Asset Viewer displays is decoded by core/dds.py (pure
#   python) and then re-encoded to PNG by Pillow. Pillow also writes the .dds
#   files produced by the mod-staging flow, and reads the handful of assets in
#   a typical install that are a JPEG or BMP wearing a .dds extension.
#   Tested with 12.3.0.
pillow>=10.0

# STRONGLY RECOMMENDED, and required for thumbnails.
#   Optional for browsing: core/dds.py has a pure-python fallback for every
#   path, it is just slower. NOT optional for tools/thumbs.py, which is a
#   numpy software rasteriser.
#   Tested with 2.5.1.
numpy>=1.24
