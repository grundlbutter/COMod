Asset library

      
    

    

      A COmmunity Library is a folder where this tool stores
      clients it has imported — one servers/<name>/ profile
      per private server, each one that server's own game install. Pick a
      folder here and those clients appear under Private server clients
      in the path menu at the top left, alongside your installed clients —
      they are clients, not "libraries"; the library is only where their bytes
      are kept. Your game install in Program Files is never modified.

Camera behaviour

      
unlockedthe angle carries over from asset to asset; the distance re-fits to
        each model so a 5-unit weapon and a 170-unit body both fill the frame

      
lockedthe view is completely frozen — angle, zoom, pan and orbit centre.
        Best for flipping through colour variants of one mesh. R always gets you back.
