Where is Conquer Online installed?

This repository ships no game assets — every texture, mesh and map it shows is read straight out of your own copy of the client. It could not find one, so it needs to be told where yours is.

The install is used read-only. Nothing in this tool writes to it except comod.py install, which you have to run deliberately and which takes a backup first.

Each choice is a parser plugin — a module that knows how one flavour of client stores its tables, ids and colours. The plugin verifies the folder is its kind before anything is saved, and plugins are discovered from plugins/, so a contributor can add one for a patch level or private server without touching the app.
