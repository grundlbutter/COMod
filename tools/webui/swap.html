Mod staging

Staged files live in mods/stage. Nothing touches the game install until you press Install, which runs comod.py install --yes — the same path as the CLI, with its backups and its uninstall revert.

Installed, by date

Each install or amendment is its own dated entry with its own backups. A revert peels them back newest first, because a later entry's backup holds what the one before it left behind.
